## Fallback and persistence

`EnvironmentFallback` centralizes actual-first reads, response checks, transport/server failure handling, account-scoped caches, demo fixtures, and local records. Every request attempts the actual service. Visible fallback screens retry every 20 seconds; manual refresh remains available. Successful live data always wins. A missing provider can use an individually labelled example while successful parts remain actual.

- Red dot: actual API/model output. Previously cached actual data retains a red dot and explicitly says saved actual data, not live.
- Black dot: prepared demonstration example. Demo classification previews show the example asset, not the user's photo as if inferred.
- Missing evaluation artifacts do not trigger fabricated metrics or history.
- Authentication, ownership, invalid image, and other client validation errors remain unsuccessful operations. They do not become simulated successes.
- Database outages can still permit image-only actual inference. Backend saving requires verified hive ownership; a failed save is never labelled saved remotely.

Fixtures live in `assets/demo/environment_disease_demo.json` and are bundled through pubspec.yaml. They cover weather, apiaries/hives, monitoring, environmental history, workspace records, and example image findings. Dates are fixed demonstration dates. The model-report fixture has no fabricated evaluation or training history.

SharedPreferences storage is scoped to the current account (or guest): `environment_actual_v1` for cached actual responses, `environment_demo_v1` for local demonstration/draft records, and `environment_demo_selection_v1` for demo selection. Local saves explicitly say local only; no automatic synchronization uploads synthetic data. Demo IDs are never used to mutate actual hives. When an actual save fails, an actual result may remain a locally labelled preview rather than a fictitious backend save. Uploaded photos remain in the session draft; original user images are not persisted by this mechanism. Demo examples use bundled photographs.
